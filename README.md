## 📌 Features
* 🛒 Product Catalog & Shopping Cart
* 🔐 User Registration & Login
* 📦 Order Tracking & Review System
* 🌐 Hosted on Render with Aiven Cloud MySQL Database

---

## 🛠️ Stack
* **Language:** PHP 8.2 (Apache)
* **Database:** Aiven Cloud MySQL
* **Container:** Docker
* **Hosting:** Render
